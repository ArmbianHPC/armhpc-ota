# v1.2.3

[简体中文](https://github.com/ArmbianHPC/armhpc-ota/blob/v1.2.3/docs/releases/v1.2.3.zh-CN.md)

- Reconnect across static System and DHCP Rescue addresses with MAC-assisted discovery and authenticated address history.
- Retain the original device and task identity when a previous IP address is reassigned.
- Preserve static network configuration priority and manual DNS settings during OTA and system recovery.

- Cancel paused controller tasks from the GUI and retain their original IDs, error details and history. Submitted device operations continue.

- Configure independent System and Rescue login accounts, with private-key/password fallback inside each saved profile.
