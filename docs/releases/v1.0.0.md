# v1.0.0

- Adds Windows GUI/CLI and Linux CLI management over SSH/SFTP and USB serial.
- Supports batch commands and upgrades with concurrency from 1 to 8, hostname filtering, and reboot reconnection.
- Provides signed system updates, Rescue A/B deployment, resumable tasks, and tool maintenance with rollback.
- Integrates shared clock recovery and NTP status across the normal system and Rescue slots.
- Adds a guided Windows MSI installer with folder selection, optional desktop shortcut, and CLI PATH integration; Linux CLI and maintenance remain available.
