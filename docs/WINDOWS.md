# Windows 管理程序

解压便携 ZIP，启动 ARMHPC-OTA.exe。命令行入口为 ARMHPC-OTA-CLI.exe --help。无需另装 .NET 或发布助手 Python。

1. 手动添加地址、导入 CSV、扫描明确指定的 IPv4 范围，或添加允许的 COM。
2. 设置单台或默认登录，认证设备并核对身份。凭据使用 Windows DPAPI 本地保存。
3. 勾选设备，按主机名或环境筛选，选择并发 1–8。隐藏设备不参与选中操作。
4. 发送 ARMHPC 命令、更新 OTA 工具，或选择本地签名系统包推送升级。

维护包默认位于 maintenance/maintenance.tar.xz；移动同一个包可按原 SHA256 重新定位，切换包需核对设备任务状态。

重启导致连接断开时，按原持久任务重连查询。结果未知不自动重发写入命令，可按选择继续后续设备。设备换 IP 后核对持久设备 ID；串口只使用明确登记的端口。

SSH 指纹验证默认启用，可对当前会话临时忽略；设备 ID 与升级身份核对继续执行。窗口关闭不停止设备服务任务；文件发布服务独立启停。
