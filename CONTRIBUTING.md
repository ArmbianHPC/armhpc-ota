# Contributing

[简体中文](CONTRIBUTING.zh-CN.md)

Follow the [ARMHPC contribution guide](https://github.com/ArmbianHPC/.github/blob/main/CONTRIBUTING.md) and [single-maintainer workflow](https://github.com/ArmbianHPC/.github/blob/main/GOVERNANCE.md).

For this repository, read [build instructions](docs/BUILD.md) and [maintenance](docs/MAINTENANCE.md). Submit a focused PR; required checks must pass, with zero additional approving reviewers. Preserve the licenses declared by each file and the repository's source/license mapping. English and Simplified Chinese contributions are welcome.
